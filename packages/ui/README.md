# @smart-wizard/ui

**CSS styles, themes, and design tokens for SmartWizard.**

> This package is part of the **[SmartWizard](https://github.com/techlab/smart-wizard)** project, the next-generation continuation of the popular jQuery SmartWizard.

## 📥 Installation

```bash
npm install @smart-wizard/ui
```

---

## ⚡ Usage

```javascript
// Bundler imports (Vite, Next.js, Webpack, etc.):
import '@smart-wizard/ui/full';              // Core styles + layouts
import '@smart-wizard/ui/themes/arrows.css'; // Optional theme (arrows, pills)
```

```html
<!-- Or via HTML link tags: -->
<link rel="stylesheet" href="node_modules/@smart-wizard/ui/dist/smartwizard-full.css" />
<link rel="stylesheet" href="node_modules/@smart-wizard/ui/dist/themes/arrows.css" />
```
